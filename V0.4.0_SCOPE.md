# ForgeFlow MCP v0.4.0 — Production Hardening

## Goal
Make the published MCP package safer and more predictable for real-world MCP hosts without coupling ForgeFlow to any single client.

## Release gates
- TypeScript lint passes on Node 20, 22, and 24.
- Unit/regression tests pass.
- Docker image builds and `/health` smoke test passes.
- Provider routing remains deterministic for explicit provider selection.
- Automatic routing may fallback only when the selected provider fails.
- Provider-specific operation/model mapping remains operation-aware.
- HTTP authentication, rate limiting, request-size limits, and graceful shutdown remain enforced.
- No API keys or credentials are committed to the repository.
- Release is published only after CI is green.

## Non-goals for v0.4
- No mandatory database.
- No provider lock-in.
- No OAuth requirement for local/stdio usage.
- No persistent job queue requirement.
